# Unemployment Analysis in India

## Project Overview
This project analyzes unemployment trends in India using Python and data visualization.

## Objectives
- Analyze unemployment rates over time.
- Compare unemployment rates across different regions.
- Calculate the average unemployment rate.
- Visualize the findings using graphs.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Dataset
Unemployment in India dataset containing regional and unemployment-related information.

## Project Files
- `unemployment_analysis.py` – Python source code.
- `Unemployment in India.csv` – Main dataset.
- `monthly_unemployment_trend.png` – Monthly trend visualization.
- `region_unemployment.png` – Region-wise visualization.

## How to Run
Install the required libraries:

```bash
py -m pip install pandas matplotlib
```

Run the project:

```bash
py unemployment_analysis.py
```

## Conclusion
The project explores unemployment patterns in India through data analysis and graphical visualization.
